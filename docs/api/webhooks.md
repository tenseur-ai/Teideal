# Billing webhooks

Webhook endpoints receive tenant billing events as JSON `POST` requests. An
empty `subscribed_events` array subscribes the endpoint to every supported
event. Delivery requests include `X-Teideal-Event-Id`,
`X-Teideal-Event-Type`, and `X-Teideal-Signature` headers.

## POST /webhook-endpoints [ts-console]

- **Auth:** Owner, Billing Admin, or Developer session.
- **Request:** JSON `url` (HTTP or HTTPS) and optional `subscribed_events` array. Supported values are `threshold.reached`, `balance.depleted`, `grant.expiring_soon`, `grant.expired`, `reservation.overrun`, `reconciliation.mismatch`, `customer.suspended`, and `period_close_sync.stalled`.
- **Response:** `201 {id,url,secret,subscribed_events,active,created_at,updated_at}`. The signing `secret` is generated by the server.
- **Errors:** `400` invalid URL or event type; `401` invalid session; `403` disallowed role.

```bash
curl -X POST "$TS_CONSOLE_URL/webhook-endpoints" -H "authorization: Bearer $SESSION_TOKEN" -H 'content-type: application/json' -d '{"url":"https://billing.example.test/teideal","subscribed_events":["threshold.reached","balance.depleted"]}'
```

## GET /webhook-endpoints [ts-console]

- **Auth:** Owner, Billing Admin, or Developer session.
- **Request:** No parameters; results are scoped to the caller's tenant.
- **Response:** `200 {data:[{id,url,secret,subscribed_events,active,created_at,updated_at}]}`. The signing secret remains visible on reads.
- **Errors:** `401` invalid session; `403` disallowed role.

```bash
curl "$TS_CONSOLE_URL/webhook-endpoints" -H "authorization: Bearer $SESSION_TOKEN"
```

## PATCH /webhook-endpoints/:id [ts-console]

- **Auth:** Owner, Billing Admin, or Developer session.
- **Request:** Endpoint UUID and at least one of JSON `url`, `subscribed_events`, or `active`.
- **Response:** `200` the complete updated endpoint, including its signing secret.
- **Errors:** `400` invalid UUID/body/URL/event type; `401` invalid session; `403` disallowed role; `404` endpoint not found for this tenant.

```bash
curl -X PATCH "$TS_CONSOLE_URL/webhook-endpoints/$WEBHOOK_ENDPOINT_ID" -H "authorization: Bearer $SESSION_TOKEN" -H 'content-type: application/json' -d '{"active":false}'
```

## DELETE /webhook-endpoints/:id [ts-console]

- **Auth:** Owner, Billing Admin, or Developer session.
- **Request:** Endpoint UUID.
- **Response:** `204` with no body.
- **Errors:** `400` invalid UUID; `401` invalid session; `403` disallowed role; `404` endpoint not found for this tenant.

```bash
curl -X DELETE "$TS_CONSOLE_URL/webhook-endpoints/$WEBHOOK_ENDPOINT_ID" -H "authorization: Bearer $SESSION_TOKEN"
```

## GET /webhook-deliveries [ts-console]

- **Auth:** Owner, Billing Admin, or Developer session.
- **Request:** Optional `event_type`, `status` (`pending`, `sent`, or `exhausted`), delivery UUID `cursor`, and positive integer `limit` (default 50, maximum 500).
- **Response:** `200 {data:[{id,event_id,event_type,endpoint_id,endpoint_url,status,attempt_count,last_http_status,last_response_body,first_attempted_at,next_retry_at,created_at}],next_cursor}`.
- **Errors:** `400` invalid filter or pagination value; `401` invalid session; `403` disallowed role.

```bash
curl "$TS_CONSOLE_URL/webhook-deliveries?event_type=threshold.reached&status=sent&limit=50" -H "authorization: Bearer $SESSION_TOKEN"
```

## GET /webhook-deliveries/:id [ts-console]

- **Auth:** Owner, Billing Admin, or Developer session.
- **Request:** Delivery UUID.
- **Response:** `200` the delivery-log row plus `attempts:[{attempt_number,outcome,http_status,response_body,attempted_at}]` in attempt order.
- **Errors:** `400` invalid UUID; `401` invalid session; `403` disallowed role; `404` delivery not found for this tenant.

```bash
curl "$TS_CONSOLE_URL/webhook-deliveries/$WEBHOOK_DELIVERY_ID" -H "authorization: Bearer $SESSION_TOKEN"
```

## POST /webhook-deliveries/:id/resend [ts-console]

- **Auth:** Owner, Billing Admin, or Developer session.
- **Request:** Delivery UUID; no body. Resend is allowed for pending, sent, and exhausted deliveries.
- **Response:** `200` the updated delivery plus its complete `attempts` array. Every resend preserves the original event ID and exact body.
- **Errors:** `400` invalid UUID; `401` invalid session; `403` disallowed role; `404` delivery not found for this tenant.

```bash
curl -X POST "$TS_CONSOLE_URL/webhook-deliveries/$WEBHOOK_DELIVERY_ID/resend" -H "authorization: Bearer $SESSION_TOKEN"
```

## Verifying webhook signatures

Read the request body as raw bytes before parsing JSON. Compute the lowercase
hex HMAC-SHA256 of that exact body using the endpoint's `secret`, prefix it
with `sha256=`, and compare it to `X-Teideal-Signature` with a constant-time
comparison. Reject missing or unequal signatures. The event ID in
`X-Teideal-Event-Id` is stable across retries and manual resends, so persist
processed IDs to make the receiver idempotent. `X-Teideal-Event-Type`
identifies the event catalog entry.

```ts
import { createHash, createHmac, timingSafeEqual } from "node:crypto";

const expected = `sha256=${createHmac("sha256", secret).update(rawBody).digest("hex")}`;
const valid = timingSafeEqual(
  createHash("sha256").update(expected).digest(),
  createHash("sha256").update(signatureHeader).digest(),
);
```
